========================================
智剧通 Windows 启动文件说明
========================================

【启动文件】
----------------------------------------

1. 点我启动.exe/点我启动.bat（推荐）
   - 软件安装路径不能有中文
   - 不能用IE浏览器打开
   - 双击即可启动服务
   - 在系统托盘显示启动状态图标
   - 启动过程中会显示气泡提示（正在启动MySQL...等）
   - 服务就绪后自动打开浏览器
   - 右键托盘图标可查看日志或退出
   - 程序包已内置完整 Python 3.10，uv 负责隔离环境和依赖，不要求安装或下载 Python
   - 首次启动创建 bin/runtime/launcher-<hash>，后续直接复用

2. start_silent.vbs
   - VBS 脚本，静默启动（备用方案）
   - 不显示托盘图标

3. start.bat
   - 批处理脚本，显示详细日志
   - 适合调试或查看启动过程

【启动流程】
----------------------------------------
点我启动.exe/点我启动.bat
    ↓
launcher_me.bat
    ↓
scripts/launchers/bootstrap.py（uv 持久化环境引导器）
    ↓
bin/runtime/launcher-<hash>/Scripts/pythonw.exe
    ↓
scripts/launchers/launcher.py（系统托盘）
    ↓
start.bat
    ↓
scripts/launchers/start_windows.py（Windows 启动管理器）
    ↓
1. 检查并更新配置文件（ffmpeg 路径等）
2. 启动 MySQL 服务
3. 首次运行时自动初始化数据库
4. 启动 Web 服务（run_prod.py）
5. 自动打开浏览器
6. 持续监控服务状态

【配置文件】
----------------------------------------
- config_prod.yml：生产环境配置
- 首次启动时从 config.example.yml 自动创建
- ffmpeg/ffprobe 路径会自动更新为当前目录

【注意事项】
----------------------------------------
- 安装路径不能有中文
- 确保 bin/mysql 目录存在（MySQL 服务）
- 确保 bin/ffmpeg 目录存在（视频处理）
- 确保 bin/uv/uv.exe 和 bin/python/cpython-3.10.20-windows-x86_64-none/python.exe 存在
- bin/python 必须是完整 Python 的 uv managed 安装根目录，不能是带 pyvenv.cfg 的普通虚拟环境
- 用户启动时禁止下载 Python，不使用系统 Python，也不写用户 AppData；缺失或损坏请重新完整解压程序包
- 不要在程序运行期间执行 uv cache clean
- 关闭窗口或按 Ctrl+C 停止服务

【启动日志】
----------------------------------------
- logs/launcher_bootstrap.log：uv/Python/托盘环境准备
- logs/launcher_runtime.log：托盘进程自身输出
- logs/startup.log：start.bat、MySQL 和 Web 服务启动输出

========================================
推荐使用"点我启动.exe"，简单方便！
========================================

【项目结构说明】
----------------------------------------
为了更好的项目组织，部分脚本已重新分类：
- scripts/launchers/ - 启动器脚本（如 start_windows.py）
- scripts/tools/ - 工具脚本（如 create_shortcuts.vbs）
- scripts/running/ - 运行脚本（如 run_prod.py）

注意：这不影响使用方式，所有启动操作保持不变。
