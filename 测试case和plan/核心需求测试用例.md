## 三、模块 1：视频工作流 · 时间轴 v2（TC-TL，37 条）★ 重点

**先认识几个词**（最容易出错的地方）：

| 词 | 意思 |
|----|------|
| 节点 | 画布上的方块（一段视频、一张图、一段配音） |
| 片段 | 时间轴上的那段。片段只是「引用」节点里的媒体，**删片段 ≠ 删节点** |
| 失物找回 | 只回收**画布上删掉的节点**。时间轴上删掉的片段**不进**失物找回 |
| 引用 | 「删除引用」= 只把片段从时间轴拿掉，节点和视频文件都还在 |

**时间轴工具栏**（展开后面板上方一排图标，从左到右）：① 红色垃圾桶带叉 = 删除引用　② 左弯箭头 = 撤销　③ 剪刀 = 分割　④ − 缩小　⑤ ＋ 放大　⑥ 绿色摄像机 = 导出成品视频　⑦ 绿色场记板 = 导出剪映草稿　⑧ 包裹 = 导出素材包　⑨ 红色橡皮擦 = 清空　⑩ 向下箭头 = 收起

### A. 基本操作

**TC-TL-01 🔴 加入时间轴**（消耗算力：否）

- 前置条件：工作流里有 2 个已生成视频的视频节点
- 操作步骤：
  1. 在视频节点上点「加时间轴」
- 预期结果：片段出现在「视频 1」轨；提示「已添加到时间轴 - 镜头N」或「已添加到时间轴 - 独立片段」；时间轴收起时右下角「展开」按钮闪一下

**TC-TL-02 🔴 没有视频的节点不能加**（消耗算力：否）

- 操作步骤：
  1. 在一个还没生成视频的视频节点上点「加时间轴」
- 预期结果：提示「请先生成或上传视频」，时间轴没有变化

**TC-TL-03 🔴 多轨叠放**（消耗算力：否）

- 操作步骤：
  1. 点「＋ 添加视频轨道」加到 3 条轨
  2. 把一个片段放到「视频 2」，让它和「视频 1」的某个片段时间重叠
  3. 播放到重叠的位置
- 预期结果：加轨成功；重叠处预览显示**轨号大的**（视频 2）画面；视频轨最多 6 条，加满后「＋ 添加视频轨道」消失

**TC-TL-04 🔴 拖动、换轨、磁吸**（消耗算力：否）

- 操作步骤：
  1. 按住一个片段左右拖
  2. 拖到另一个片段的边缘附近再松手
  3. 把视频片段拖到音频轨上
  4. 把片段拖到轨道区域外面
  5. 把片段拖到「＋ 添加视频轨道」这一行上
- 预期结果：① 拖动时有跟随的半透明影子，目标轨高亮　② 靠近时出现**橙色竖线**并自动吸过去　③④ 松手后片段弹回原位，不动　⑤ 自动新增一条轨并放进去

**TC-TL-05 🔴 裁剪片段**（消耗算力：否）

- 操作步骤：
  1. 把鼠标放到片段最左/最右，出现蓝色竖条后往里拖
  2. 一直拖到不能再拖
  3. 右键片段 →「打开剪切对话框」，改起止时间后确定
- 预期结果：① 片段变短，时间轴上的宽度跟着变　② 最短只能裁到 0.1 秒　③ 提示「剪切成功」，片段按新起止时间显示

**TC-TL-06 🔴 分割（快捷键 S）**（消耗算力：否）

- 操作步骤：
  1. 点刻度尺，把播放头放进某个片段内部
  2. 选中这个片段，按键盘 S
  3. 把播放头移到片段外面，再选中片段按 S
- 预期结果：② 片段一分为二，提示「已分割片段」，右半段处于选中状态　③ 提示「播放头不在片段内部：请先点击刻度尺把播放头移到片段内」
- 留意：按 Ctrl+S（本意保存网页）也会触发分割 ⚠️ K-TL-04，按实际现象记录

**TC-TL-07 🔴 删除引用的 4 种方式**（消耗算力：否）

- 操作步骤：
  1. 分别用 ① Delete 键　② Backspace 键　③ 工具栏第①个红色按钮　④ 右键片段 → 删除片段，各删一个片段
  2. 每次删完按 Ctrl+Z
- 预期结果：片段从时间轴消失（没有提示）；**画布上的节点和视频都还在**；失物找回角标数字**不变**；Ctrl+Z 后片段回到原来的轨、原来的位置，提示「已撤销上一步操作」

**TC-TL-08 🟡 没选中时点「删除引用」**（消耗算力：否）

- 操作步骤：
  1. 不选任何片段，点工具栏红色「删除引用」按钮
- 预期结果：提示「请先选中要删除的片段（点击片段选中，Ctrl 多选）」，没有任何东西被删

**TC-TL-09 🔴 多选删除**（消耗算力：否）

- 操作步骤：
  1. 按住 Ctrl 依次点 3 个片段，按 Delete
  2. 按 Ctrl+Z
- 预期结果：3 个片段一起消失；撤销后 3 个一起回来

**TC-TL-10 🔴 清空时间轴**（消耗算力：否）

- 操作步骤：
  1. 时间轴上有若干片段时，点工具栏红色「清空」→ 确定弹窗
  2. 之后按 Ctrl+Z
- 预期结果：弹窗「确定要清空时间轴吗？」；确定后所有片段消失，提示「时间轴已清空」；**画布节点都还在**；轨道数量不变；失物找回角标不变；Ctrl+Z 能全部恢复

**TC-TL-11 🟡 增删轨道**（消耗算力：否）

- 操作步骤：
  1. 把鼠标放到轨道名「视频 2」上
  2. 点出现的「×」
  3. 在一条有片段的轨道上点「×」
  4. 看只有 1 条轨的音频组
- 预期结果：① 出现「×」，提示「删除此空轨道」　② 空轨被删，提示「已删除空的视频轨道」，上面轨道的编号自动补上　③ 提示「「视频 2」轨道上还有 N 个片段，请先移走或删除」，删不掉　④ 只有 1 条轨时不显示「×」

**TC-TL-12 🟡 播放和快捷键**（消耗算力：否）

- 操作步骤：
  1. 按空格键，再按一次
  2. 点刻度尺不同位置
  3. 点「回到开头」按钮
  4. 光标在输入框里时按 S、空格、Delete
  5. 打开任意一个弹窗后按 S、空格
- 预期结果：① 播放 / 暂停　② 播放头跳到点击的位置　③ 播放头回到 0　④⑤ 时间轴**不响应**这些按键，输入和弹窗正常

**TC-TL-13 🟡 音频轨**（消耗算力：否）

- 操作步骤：
  1. 给音频节点（或 TTS 配音、对话组）点「添加到时间轴」
  2. 把一段音频拖到某段视频的分界线附近
  3. 把音频拖到视频轨上
  4. 在两条音频轨上放两段重叠的音频并播放
- 预期结果：① 落在音频轨　② 靠近时出现橙色竖线并吸附　③ 弹回，放不进视频轨　④ 两段声音同时播放

**TC-TL-14 🟡 右键菜单和跳转**（消耗算力：否）

- 操作步骤：
  1. 右键一个视频片段
  2. 右键一个音频片段
  3. 点「跳转到节点」
  4. 双击一个片段
- 预期结果：① 有 4 项（打开剪切对话框、在播放头处分割、跳转到节点、删除片段）　② 3 项（没有剪切对话框）　③④ 画布自动滚到对应节点并选中它

### B. 失物找回与撤销

**TC-TL-15 🔴 删除带片段的视频节点**（消耗算力：否）

- 前置条件：一个视频节点已加入时间轴，并且和图片节点连了线
- 操作步骤：
  1. 在画布上删除这个视频节点 → 点「确定」
- 预期结果：先弹确认「该视频节点在时间轴中有 N 个片段，删除节点将同时删除这些片段。确定要删除吗？」；确定后节点消失、时间轴上对应片段一起消失、左下角失物找回角标 +1；屏幕中下方出现提示「已删除「节点名」，可在左下角「失物找回」恢复」，带一个「撤销」按钮，约 6 秒后消失

**TC-TL-16 🔴 删除确认框点「取消」**（消耗算力：否）⚠️ K-TL-01

- 操作步骤：
  1. 同 TC-TL-15，但在确认框点「取消」
- 预期结果（正确的行为）：节点还在，时间轴片段还在，失物找回角标**不变**，不出现「已删除」提示
- 已知问题 K-TL-01（已确认）：取消后失物找回里可能多出一条，恢复时报「画布上已存在相同编号的节点」。如复现，记「已复现」即可

**TC-TL-17 🔴 从失物找回恢复**（消耗算力：否）

- 前置条件：已做 TC-TL-15
- 操作步骤：
  1. 点左下角「失物找回」图标
  2. 找到刚删的那条 → 点「恢复」
- 预期结果：弹窗标题「失物找回」和条数；每行有缩略图、名称、「节点 · 删除于 年-月-日 时:分」、「恢复」「彻底删除」两个按钮，最新的在最上面；点恢复后节点回到画布**原来的位置**并自动聚焦（蓝色发光约 1 秒），连线恢复，时间轴片段回到原来的轨和位置；提示「已恢复「节点名」及 N 个时间轴片段」；角标 −1

**TC-TL-18 🔴 失物找回的其他按钮和上限**（消耗算力：否）

- 操作步骤：
  1. 点某条的「彻底删除」
  2. 点右下「清空失物找回」
  3. 连续删除 51 个节点后打开失物找回
  4. 刷新页面再打开失物找回
- 预期结果：① 立即删除（⚠️ K-TL-05：没有二次确认，按实际现象记录）　② 先弹「确定要清空「失物找回」吗？清空后无法再恢复。」，确定后清空，显示「失物找回是空的」　③ 只保留 50 条，最早的一条被挤掉　④ 内容还在（失物找回跟着工作流一起保存）

**TC-TL-19 🔴 失物找回入口能不能点到**（消耗算力：否）⚠️ K-TL-02

- 操作步骤：
  1. 时间轴处于**展开**状态，看画布左下角「节点管理」旁边的失物找回图标
- 预期结果（正确的行为）：图标完整可见、能点开。如果被时间轴面板盖住了，截图记录（已知问题 K-TL-02，已确认）

**TC-TL-20 🔴 撤销按钮**（消耗算力：否）

- 操作步骤：
  1. 依次做：加片段、拖动、裁剪、分割、删片段、加轨、删轨、清空、删节点、恢复节点，每做一步点一次工具栏的撤销按钮（或按 Ctrl+Z）
  2. 一直撤到底
  3. 刷新页面后再点撤销
- 预期结果：每点一次回退一步，画布、时间轴、失物找回一起回到上一步；撤到底提示「没有更多可撤销的操作」；刷新后撤销记录清空，同样提示

**TC-TL-23 🔴 打开升级前保存的旧工作流**（消耗算力：否）

## 五、模块 3：接口模块 / 用户模块（TC-UM，43 条）★ 重点（最复杂，建议约开发全程配合）

**功能背景**：平台可以接入第三方的生图/生视频接口，每接入一个就是一个「接口模块」。管理员让 AI 读接口文档、自动写出对接代码，检查没问题后启用，再挂到某个模型上，普通用户就能在模型里选到这个渠道。

**额外前置条件**（不满足很多用例做不了）：

| 需要 | 说明 |
|------|------|
| 启动方式 | 必须 `run_dev.py` / `run_prod.py` 启动（会多拉起一个 Supervisor 进程运行模块） |
| 支持「工具调用」的大模型 | 后台「模型管理」里有并关联了供应商；推荐 deepseek 的 `deepseek-v4-flash` |
| 供应商接口文档 | 找开发要（例如聚合站点的 OpenAI 兼容生图接口说明） |
| 配好密钥的站点槽位 | 如 `api_aggregator.site_1`（后台「实现方管理」里显示已配置） |
| 时间 | 每次 AI 生成要几分钟到几十分钟，单个任务最长 30 分钟 |
| 版本模式 | 向开发确认是社区版还是商业版（`edition.mode`），影响 TC-UM-27 的步骤 |
| 测试用「故障模块」 | TC-UM-32、37、40 需要能故意出错或超时的模块，请开发提前准备 |

**名词**：草稿（AI 写出来未发布的代码）/ 校验（自动检查代码）/ AI 安全审核（另一个 AI 检查安全性，高风险禁止发布）/ 批准发布（草稿定稿成不可修改的「版本」Release）/ 启用（模块对外可用）/ 绑定（把模块能力挂到模型条目上）
