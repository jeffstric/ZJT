# 智剧通（ZJT）用户使用手册

> 本文档面向终端用户，介绍智剧通平台的功能和使用方法。
> 开发者请参考 [README.md](README.md)。

---

## 一、平台简介

智剧通是一个 **AI 驱动的短剧制作平台**，支持从剧本创作到视频生成的全流程自动化。

### 核心能力

| 能力 | 说明 |
|------|------|
| AI 剧本创作 | 输入故事概念，AI 自动生成完整剧本、角色、场景 |
| 视频工作流 | 无限画布式分镜编排，一键生成视频 |
| 营销智能体 | 对话式创作，支持图片/视频生成 |
| 团队协作 | 多人实时协作，独立算力账户 |
| 多模型支持 | Qwen、Gemini、Claude、Ollama 等 10+ 模型 |

### 适用场景

- **短剧创作者**：从剧本到视频的全流程制作
- **营销团队**：快速生成带货视频、广告素材
- **教培机构**：分配独立算力，教学短视频创作
- **企业团队**：多人协作制作品牌宣传视频

## 二、快速开始

### 2.1 启动平台

#### Windows 用户

1. 双击 `点我启动.exe`
2. 等待系统托盘图标出现
3. 浏览器自动打开 http://localhost:9003/

#### macOS 用户

1. 双击 `start.command`
2. 浏览器自动打开 http://localhost:9003/

#### Linux 用户

```bash
python3 scripts/running/run_prod.py
```

访问 http://localhost:9003/

### 2.2 首次访问

1. 打开浏览器访问平台
2. 选择创作模式：**短剧模式** 或 **营销模式**
3. 注册账号（首个注册用户自动成为管理员）

## 三、功能模块

### 3.1 首页

首页是平台的入口，提供：

- **模式选择**：短剧模式 / 营销模式
- **快速入口**：视频工作流、剧本创作、营销智能体
- **算力余额**：显示当前账户剩余算力

### 3.2 剧本创作系统

路径：首页 → 剧本创作

#### 功能说明

| 功能 | 操作方式 |
|------|---------|
| 创建剧本 | 输入故事概念，点击"生成剧本" |
| 角色管理 | 左侧面板 → 角色，创建/编辑角色设定 |
| 场景管理 | 左侧面板 → 场景，设计场景背景 |
| 道具管理 | 左侧面板 → 道具，管理剧本道具 |
| AI 对话 | 右侧面板与 AI 智能体对话优化剧本 |

#### 创作流程

```
输入故事概念 → AI 生成剧本大纲 → 人工调整 → 生成完整剧本
     ↓
创建角色设定 → 生成角色参考图
     ↓
设计场景背景 → 生成场景参考图
     ↓
进入制作工坊 → 视频工作流
```

### 3.3 视频工作流

路径：首页 → 视频工作流

#### 核心概念

- **工作流**：一个视频项目，包含多个分镜
- **画布**：无限拖拽的编辑区域
- **节点**：画布上的功能单元（视频、图片、音频等）
- **分镜**：视频的基本单元，包含画面和配音

#### 节点类型

| 节点 | 功能 | 使用场景 |
|------|------|---------|
| 视频节点 | 生成/编辑视频 | 图生视频、文生视频 |
| 图片节点 | 生成/编辑图片 | 文生图、图生图 |
| 音频节点 | 语音合成 | TTS 配音、音效 |
| 分镜节点 | 分镜设计 | 管理单个分镜 |
| 对话节点 | 角色对话 | 编辑角色台词 |

#### 操作指南

**创建新工作流**
1. 点击"新建工作流"
2. 输入项目名称
3. 进入画布编辑

**添加节点**
1. 点击画布左上角"+"按钮
2. 选择节点类型
3. 拖拽到合适位置

**生成视频**
1. 完成分镜编排
2. 点击"生成"按钮
3. 等待 AI 处理（实时显示进度）

**导出视频**
1. 生成完成后，点击"导出"
2. 选择导出格式
3. 下载到本地

#### 画布操作

| 操作 | 方式 |
|------|------|
| 移动画布 | 鼠标中键拖拽 |
| 缩放 | 滚轮缩放 |
| 选择节点 | 点击节点 |
| 多选 | 框选或 Ctrl+点击 |
| 删除节点 | 选中后 Delete 键 |

### 3.4 工作流列表

路径：首页 → 视频工作流 → 工作流列表

- 查看所有工作流项目
- 创建新工作流
- 编辑/删除工作流
- 查看工作流状态

### 3.5 营销智能体

路径：首页 → 营销智能体

#### 三种创作模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **Agent 模式** | 对话式 AI 创作 | 复杂营销内容策划 |
| **图片生成** | 直接生成图片 | 产品图、海报 |
| **视频生成** | 直接生成视频 | 带货视频、广告 |

#### 使用流程

1. 选择创作模式
2. 输入创作需求描述
3. AI 生成内容
4. 优化调整
5. 导出成果

#### 会话管理

- **新建对话**：点击"+ New Chat"
- **搜索对话**：使用搜索框
- **重命名**：右键对话 → 重命名
- **删除对话**：右键对话 → 删除

### 3.6 管理后台

路径：首页 → 管理后台（需要管理员权限）

#### 功能模块

| 模块 | 功能 |
|------|------|
| **仪表盘** | 用户统计、活跃工作流、模型成功率 |
| **用户管理** | 用户列表、算力调整、角色管理 |
| **系统配置** | 模型配置、价格设置、供应商优先级 |
| **实现方管理** | API 供应商配置 |
| **签到管理** | 每日签到奖励配置 |

#### 用户管理

- **查看用户列表**：管理后台 → 用户管理
- **调整算力**：点击用户 → 调整算力
- **切换角色**：点击用户 → 切换角色（普通用户/管理员）
- **禁用/启用**：点击用户 → 状态切换

#### 系统配置

- **模型配置**：设置默认模型、API 密钥
- **价格设置**：配置各模型的算力消耗
- **供应商优先级**：设置模型调用优先级

## 四、算力系统

### 4.1 什么是算力

算力是平台内的虚拟货币，用于消耗 AI 服务：

- 文本生成：消耗较少算力
- 图片生成：消耗中等算力
- 视频生成：消耗较多算力

### 4.2 查看算力

- 首页顶部显示当前余额
- 管理后台 → 用户管理 → 查看详细记录

### 4.3 获取算力

- **每日签到**：签到获得免费算力
- **管理员调整**：管理员可手动调整用户算力
- **充值**：通过算力充值页面购买（如已配置支付）

## 五、常见问题

### 5.1 启动问题

| 问题 | 解决方案 |
|------|---------|
| 端口 9003 被占用 | 关闭占用端口的程序，或修改配置文件中的端口 |
| 数据库连接失败 | 确保 MySQL 服务已启动 |
| 页面打不开 | 检查防火墙设置，确保端口可访问 |

### 5.2 使用问题

| 问题 | 解决方案 |
|------|---------|
| 图片上传失败 | 检查图片大小（默认限制 10MB） |
| 视频生成失败 | 检查 API 配置是否正确 |
| TTS 合成失败 | 检查 TTS 服务配置 |
| 生成速度慢 | 检查网络连接，或增加 API 并发数 |

### 5.3 账号问题

| 问题 | 解决方案 |
|------|---------|
| 忘记密码 | 联系管理员重置 |
| 算力不足 | 每日签到或联系管理员充值 |
| 权限不足 | 联系管理员调整角色 |

## 七、最佳实践

### 7.1 短剧创作建议

1. **先写好剧本**：剧本质量决定视频质量
2. **角色设定详细**：详细的设定有助于 AI 生成一致的图像
3. **场景风格统一**：保持美术风格一致性
4. **分镜合理**：每个分镜时长控制在 3-5 秒

### 7.2 营销内容创作建议

1. **明确目标**：清楚描述想要的效果
2. **提供参考**：上传参考图片或视频
3. **多次迭代**：AI 生成后多次优化调整
4. **A/B 测试**：生成多个版本进行测试

### 7.3 算力节省技巧

1. **先用小图测试**：确认效果后再生成高清图
2. **复用素材**：已生成的图片/视频可重复使用
3. **合理设置参数**：避免不必要的高分辨率生成
