# 充值套餐首充解绑 + 首充福利包 + 订阅首订加赠翻倍（2026-09-19）

## 背景

- 体验包 9.9（package_id=1）自 2026-09-11 新价目上线起，沿用了旧"首充福利"包（0.1 元/100 算力）
  的一次性购买机制（列表过滤 / 下单拦截 / 回调置位与降级），导致已首充用户无法再次购买，
  被误认为"包下架"。业务定位纠正：**9.9 体验包为常规套餐，任意时刻可充**。
- 订阅上线初期转化不足，通过"首充福利拉新 + 首订加赠翻倍"提升转化势能。

## 一、直充套餐调整（config/constant.py）

### RECHARGE_PACKAGES 新增首充福利包

| package_id | 套餐 | 价格 | 算力 | 说明 |
|---|---|---|---|---|
| **5（新增）** | 首充福利 99 | ¥0.1 | 99 | 仅未首充用户可见/可购，一次性 |
| 1 | 体验包 88 | ¥9.9 | 88 | **常规化**：不再受首充限制 |
| 2/3/4 | 算力包 | 49.9 / 109 / 209 | 508 / 1358 / 2988 | 不变 |

### 首充机制解绑（server.py 三处硬编码 `package_id == 1` → `Commission.FIRST_RECHARGE_PACKAGE_ID`）

| 位置 | 行为 |
|---|---|
| `GET /api/recharge/packages`（列表过滤） | 已首充用户仅过滤 package_id=5；9.9 体验包对所有人可见 |
| `POST /api/recharge/wechat-pay`（下单拦截） | 已首充用户购买 package_id=5 → 400；购买 9.9 包放行 |
| `/api/recharge/wechat-callback`（置位/降级） | 仅购买 package_id=5 触发 `users.first_recharge=1`；重复购买降级 4 算力 |

- 顺带修复：列表接口 `commission/recharge_grants` 请求误用 query 的 `auth_token`，
  改用 `resolved_token`（cookie 会话/纯 header 登录下原先会发 `Bearer None`）。

### 佣金口径

- 首充福利包**不定义** `Commission.COMMISSION_TIERS` 档位 → `settle()` 走
  「未知档位 → 不抽佣全额到账」分支，与"首充不抽佣"语义一致（见 invite_commission.md）。
- 体验包 9.9（package_id=1）档位不变：`full_power=122 / invited_power=88 / channel_cash=1.46`。

### 存量用户

- `users.first_recharge=1` 的存量用户（含历史上仅购买 9.9 体验包被置位者）看不到 0.1 元福利包
  （首充资格已消耗，保持现状，未做数据订正）。
- 历史订单 package_id 语义不变（1 仍为 9.9/88），无数据迁移。

## 二、订阅首订加赠翻倍（config/subscription_config.py）

| 档位 | 每月扣费 | 每期到账 | 首订加赠 | 首期合计（抽成后） |
|---|---|---|---|---|
| 入门版 101 | ¥29.9 | 328 | 100 → **200** | 528 |
| 标准版 102 | ¥59.9 | 808 | 200 → **400** | 1208 |
| 专业版 103 | ¥129 | 2148 | 300 → **600** | 2748 |
| 旗舰版 104 | ¥299 | 5598 | 500 → **1000** | 6598 |

- 发放机制不变：`subscription_service._grant_first_period_bonus` 实时读配置，签约成功后
  独立幂等键（`{transaction_id}_FIRST_BONUS` + `first_bonus_granted`）全额发放，不参与渠道抽佣。
- 仅改配置，前端 `index.html` 绑定 `plan.first_period_bonus` 自动展示。
- 生效边界：上线时"签约中"的存量首期订单，签约成功后按**新值**发放；已发放订单幂等不受影响。

### 成本口径（内部算力成本 0.04 元/算力）

- 加赠翻倍的边际成本 = 原加赠成本再花一份：每首订用户 4 / 8 / 12 / 20 元（按档位）。
- 首期毛利（抽成口径）：入门 8.50→4.50、标准 11.98→3.98、专业 15.92→3.92、旗舰 30.20→10.20。
  续期每期毛利不变（12.50 / 19.98 / 27.92 / 50.20）。
- 设计动机：保持"付得多送得多"的档位递增梯度（每元赠送全档 ×2），
  营销文案统一为"首订加赠翻倍"。
