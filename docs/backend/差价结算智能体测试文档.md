## 0. 被测机制速览

任务按供应商A价格扣费 → 失败切换供应商B → B 成功/失败：

- **失败**：按扣费流水**原额**退（`refund-{原流水号}`，前置修复已上线）
- **成功**：按**实际完成供应商B**价格双向结算差价——多扣退差 `diff-refund-{原流水号}`（increase）、少扣补收 `diff-charge-{原流水号}`（deduct，best-effort）
- **任务过期（7天卡死）**：标记失败时原额退费（本次修复）
- 灰度开关：动态配置 `billing.settle_diff_enabled`（默认开）
- 核心：`utils/computing_power.py` 的 `settle_task_success_diff` / `settle_success_diff_for_task`
- 挂钩：5个成功终态（visual_task 同步/异步、download_queue_task ×2、sync_task_executor）+ 过期分支退费

### F. 部署后线上验证（部署 develop_f623 后执行，只读）

```sql
-- F1. 新产生的差价流水扣返一致
SELECT a.id, d.computing_power AS deducted, df.computing_power AS diff_amount,
       df.behavior, df.transaction_id
FROM ai_tools a
JOIN computing_power_log d ON d.transaction_id=a.transaction_id AND d.behavior='deduct'
JOIN computing_power_log df ON df.transaction_id IN (CONCAT('diff-refund-',a.transaction_id), CONCAT('diff-charge-',a.transaction_id))
WHERE a.status=2 AND a.completed_time >= '<部署时间>';
-- 预期：仅切换过的任务（存在 attempt>=2）出现；diff-refund 为 increase、diff-charge 为 deduct

-- F2. 差价金额正确性抽验（取 F1 一条，人工核对）
-- 实际完成供应商现价 = implementation_power_config.power_config 或代码默认价（按 duration 档位）
-- 应退差 = deducted - 实际价；与 diff_amount 相等

-- F3. 无切换任务不应有差价流水（回归确认）
SELECT COUNT(*) FROM ai_tools a
JOIN computing_power_log df ON df.transaction_id = CONCAT('diff-refund-', a.transaction_id)
WHERE a.status=2
  AND NOT EXISTS (SELECT 1 FROM implementation_attempts ia WHERE ia.ai_tool_id=a.id AND ia.attempt_number>=2);
-- 预期：0

-- F4. 异常并存监控（终态竞态，长期对账项）
SELECT a.id FROM ai_tools a
WHERE EXISTS (SELECT 1 FROM computing_power_log r WHERE r.transaction_id=CONCAT('refund-',a.transaction_id))
  AND EXISTS (SELECT 1 FROM computing_power_log d WHERE d.transaction_id=CONCAT('diff-refund-',a.transaction_id));
-- 预期：0（同任务全额退费与差价结算不应并存）
```
