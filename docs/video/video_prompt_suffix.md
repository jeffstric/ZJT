# 视频提示词后缀

## 概述

视频提示词后缀是一个全局设置，用于在所有视频生成任务的提示词末尾自动添加统一的后缀文本。

## 功能

| 功能 | 说明 |
|------|------|
| 全局后缀 | 设置一次，所有视频节点生效 |
| 自动附加 | 生成视频时自动添加到提示词末尾 |
| 统一风格 | 确保所有视频保持一致的风格描述 |

## 设置方法

1. 点击画布顶部的「后缀」按钮
2. 在弹窗中输入后缀文本
3. 点击「保存」

## 使用场景

### 统一视频风格

```
后缀：cinematic, high quality, smooth motion
```

所有视频生成时，提示词末尾会自动添加这些描述。

### 统一画面质量

```
后缀：4K, ultra HD, professional lighting
```

### 统一运动风格

```
后缀：slow camera movement, dramatic angle
```

## 效果示例

假设原始提示词为：`一个女孩在花园里散步`

设置后缀为：`cinematic, high quality`

实际发送的提示词为：`一个女孩在花园里散步, cinematic, high quality`

## 注意事项

- 后缀对所有图生视频节点生效
- 修改后缀后需要重新生成视频才能看到效果
- 后缀不宜过长，建议控制在 50 字以内
