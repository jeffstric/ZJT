# 音频节点使用指南

## 概述

音频节点用于存储和管理音频文件，可以接收对话组或文字转语音节点的输出，也可以直接上传音频。

## 功能

| 功能 | 说明 |
|------|------|
| 上传音频 | 支持本地音频文件上传 |
| 音频预览 | 点击预览按钮播放音频 |
| 添加到时间轴 | 将音频添加到时间轴进行编排 |
| 接收输入 | 通过连接线接收对话组或TTS节点的输出 |

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 输入端口 | 左侧 | 接收对话组或文字转语音节点的输出 |

## 使用方式

### 方式一：直接上传

1. 添加音频节点
2. 点击上传区域选择本地音频文件
3. 等待上传完成

### 方式二：连接其他节点

1. 先创建对话组或文字转语音节点
2. 从输出端口拖拽连接到音频节点
3. 音频自动填充到节点中

## 支持格式

- MP3、WAV、M4A、AAC、OGG、FLAC、WMA

## 注意事项

- 音频文件大小受配置限制
- 添加到时间轴后可在时间轴面板中编排顺序和时长
