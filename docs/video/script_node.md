# 剧本节点使用指南

## 概述

剧本节点用于导入和管理剧本内容，支持自动解析剧本生成分镜组和分镜头。

## 功能

| 功能 | 说明 |
|------|------|
| 剧本导入 | 支持文本输入或从剧本创作系统导入 |
| 自动解析 | AI 自动将剧本拆分为分镜组和分镜头 |
| 角色匹配 | 自动识别剧本中的角色标记 |
| 分镜生成 | 基于剧本内容自动生成分镜 |

## 剧本格式

### 角色标记

- 使用 `【【角色名】】` 标记角色台词
- 系统会自动匹配已创建的角色

### 场景标记

- 剧本中的场景描述会被识别为场景节点

## 自动解析流程

1. 输入或导入剧本内容
2. 点击「解析」按钮
3. AI 自动分析剧本结构
4. 生成分镜组（每个场景为一个分镜组）
5. 生成分镜头（每句台词或动作为一个分镜头）

## 与分镜系统的关系

- 剧本节点 → 生成分镜组节点
- 分镜组节点 → 包含多个分镜节点
- 分镜节点 → 生成图片和视频

## 注意事项

- 剧本解析需要消耗算力
- 解析结果可能需要人工调整
- 支持增量同步，修改剧本后可重新解析
