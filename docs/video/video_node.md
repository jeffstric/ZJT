# 视频节点使用指南

## 概述

视频节点用于存储和管理视频文件，可以接收图生视频节点的输出，也可以直接上传视频。

## 功能

| 功能 | 说明 |
|------|------|
| 上传视频 | 支持本地视频文件上传 |
| 上传中标识 | 视频上传期间预览缩略图左上角显示"上传中..."旋转标识，提醒当前仅为本地临时预览、服务器地址尚未就绪 |
| 视频预览 | 点击预览按钮查看视频 |
| 添加到时间轴 | 将视频添加到时间轴进行编排 |
| 接收输入 | 通过连接线接收图生视频节点的输出 |

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 输入端口 | 左侧 | 接收图生视频节点的输出 |

## 使用方式

### 方式一：直接上传

1. 添加视频节点
2. 点击上传区域选择本地视频文件
3. 等待上传完成

### 方式二：连接图生视频

1. 先创建图生视频节点并生成视频
2. 从图生视频节点的输出端口拖拽连接到视频节点
3. 视频自动填充到节点中

## 注意事项

- 上传的视频会存储到服务器
- 视频文件大小受配置限制
- 添加到时间轴后可在时间轴面板中编排顺序
- 上传完成前视频地址为浏览器本地临时地址（blob:），此时连接到其他节点（如提取帧）
  拿不到服务器地址；其他节点会在提取时实时回读或提示等待，待"上传中..."标识消失后再操作即可
