# 分镜节点使用指南

## 概述

分镜节点是视频工作流的基本创作单元，每个分镜包含一张图片和对应的视频。分镜节点支持 AI 生成图片和视频。

## 功能

| 功能 | 说明 |
|------|------|
| 分镜图生成 | 使用 AI 生成分镜图片 |
| 分镜视频生成 | 基于分镜图片生成视频 |
| 首帧模式 | 使用已有图片作为视频首帧 |
| 参考图模式 | 使用参考图辅助生成 |
| 角色/场景/道具参考 | 自动收集关联资产的参考图 |

## 分镜图生成

### AI 生成

1. 输入图片描述提示词
2. 选择画风（跟随工作流设置）
3. 点击「生成图片」
4. 等待 AI 生成

### 手动上传

- 直接上传本地图片作为分镜图

## 分镜视频生成

### 首帧模式

- 使用分镜图作为视频首帧
- AI 根据首帧和提示词生成视频

### 参考图模式

- 使用分镜图作为参考图之一
- 可额外添加角色、场景、道具的参考图
- AI 综合所有参考图生成视频

## 参考图收集

分镜节点会自动从关联资产中收集参考图：

- **角色参考图**：分镜关联的角色的参考图
- **场景参考图**：分镜关联的场景的参考图
- **道具参考图**：分镜关联的道具的参考图

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 图片输出 | 右侧 | 连接到图片节点或图生视频节点 |
| 视频输出 | 右侧 | 连接到视频节点 |

## 使用流程

1. 从剧本节点自动生成分镜，或手动创建分镜节点
2. 生成或上传分镜图片
3. 选择视频生成模式
4. 生成视频
5. 通过连接线传递到视频节点
6. 添加到时间轴进行最终编排
