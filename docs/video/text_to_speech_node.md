# 文字转语音节点使用指南

## 概述

文字转语音（TTS）节点用于将文本转换为语音音频，支持参考音色、情感控制等功能。

## 功能

| 功能 | 说明 |
|------|------|
| 文本输入 | 输入要转换的文本内容 |
| 参考音色 | 上传参考音频，模仿其音色 |
| 情感控制 | 通过情绪参考音频控制语音情感 |
| 情绪权重 | 调整情绪表达的强度 |

## 参数设置

| 参数 | 说明 |
|------|------|
| 文本 | 要转换为语音的文字内容 |
| 参考音色 | 上传参考音频文件，AI 会模仿其音色 |
| 情绪参考音频 | 上传带有特定情绪的音频作为参考 |
| 情绪权重 | 0-100，控制情绪表达的强度 |

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 音色输入 | 左侧紫色 | 接收角色节点的音色输出，或音频节点的输出。连上后走参考音频克隆：角色用其 `default_voice`，音频节点用其文件地址。没有可用参考音时不建立连接，并提示。音色库下拉仍然保留 |
| 音频输出 | 右侧 | 连接到音频节点，或图生视频的音频输入 |

## 音色来源

音色可以来自三处，互不排斥：

1. **音色库**：合成引擎选「音色库合成」，从下拉列表选火山音色。
2. **本地参考音频**：合成引擎选「参考音频克隆」，自己上传参考音。
3. **连线**：从角色节点右下角的紫色「音色输出」拖到本节点的「音色输入」；音频节点的输出也可以拖到这个输入点。对话组每条台词右侧的圆点，在该角色匹配到当前世界角色且有参考音时，同样可以拖到这个输入点。一个文字转语音节点只保留一条音色连线，新的连线会替换旧的。

断开这条连线、清除参考音，或删除来源节点后，若参考音是连线带入的，合成引擎回到音色库。重新打开工作流时，会按保存的音色连线再次填上参考音。角色节点重新加载后，音色输出口仍在。

## 参考音色

- 上传一段参考音频（建议 10-20 秒）
- AI 会学习该音频的音色特征
- 生成的语音会模仿参考音色
- 支持 mp3、wav、m4a 等格式

## 情感控制

- 上传带有目标情绪的音频片段
- 设置情绪权重（越高越接近参考情绪）
- 适合需要特定情感表达的配音场景

## 使用流程

1. 添加文字转语音节点
2. 输入文本内容
3. （可选）上传参考音色音频
4. （可选）上传情绪参考音频并设置权重
5. 点击「生成」
6. 等待生成完成
7. 通过连接线将输出连接到音频节点
