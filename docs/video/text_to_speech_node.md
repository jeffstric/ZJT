# 文字转语音节点使用指南

## 概述

文字转语音（TTS）节点用于将文本转换为语音音频，支持参考音色、情感控制等功能。

## 功能

| 功能 | 说明 |
|------|------|
| 文本输入 | 输入要转换的文本内容 |
| 参考音色 | 上传参考音频，模仿其音色 |
| 情感控制 | 通过情绪参考音频控制语音情感 |
| 情绪权重 | 调整情绪表达的强度 |

## 参数设置

| 参数 | 说明 |
|------|------|
| 文本 | 要转换为语音的文字内容 |
| 参考音色 | 上传参考音频文件，AI 会模仿其音色 |
| 情绪参考音频 | 上传带有特定情绪的音频作为参考 |
| 情绪权重 | 0-100，控制情绪表达的强度 |

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 音频输出 | 右侧 | 连接到音频节点 |

## 参考音色

- 上传一段参考音频（建议 10-20 秒）
- AI 会学习该音频的音色特征
- 生成的语音会模仿参考音色
- 支持 mp3、wav、m4a 等格式

## 情感控制

- 上传带有目标情绪的音频片段
- 设置情绪权重（越高越接近参考情绪）
- 适合需要特定情感表达的配音场景

## 使用流程

1. 添加文字转语音节点
2. 输入文本内容
3. （可选）上传参考音色音频
4. （可选）上传情绪参考音频并设置权重
5. 点击「生成」
6. 等待生成完成
7. 通过连接线将输出连接到音频节点
