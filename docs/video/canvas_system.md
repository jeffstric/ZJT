# 画布系统使用说明

## 概述

画布是视频工作流的核心编辑区域，支持无限拖拽、缩放、节点管理等操作。

## 画布操作

### 缩放

| 操作 | 方式 |
|------|------|
| 放大 | 点击右下角 `+` 按钮，或 `Ctrl + 滚轮` |
| 缩小 | 点击右下角 `−` 按钮，或 `Ctrl + 滚轮` |
| 缩放范围 | 25% ~ 200% |
| 当前缩放 | 右下角显示当前百分比 |

### 平移

| 操作 | 方式 |
|------|------|
| 移动画布 | 鼠标中键拖拽，或 `空格 + 左键拖拽` |
| 重置位置 | 刷新页面自动恢复上次位置 |

### 小地图（Minimap）

- 位于画布右下角
- 显示所有节点的缩略位置
- 蓝色方框表示当前视口范围
- 点击小地图可快速导航到指定位置

## 节点操作

### 添加节点

1. 点击画布左上角 `+` 按钮
2. 在弹出菜单中选择节点类型
3. 节点会出现在画布当前视口中心

### 选择节点

| 操作 | 方式 |
|------|------|
| 单选 | 点击节点 |
| 多选 | `Ctrl + 点击` 添加到选区 |
| 框选 | 在空白区域按住左键拖拽 |
| 全选 | `Ctrl + A` |

### 移动节点

- 选中节点后拖拽移动
- 多选时拖拽其中一个，其他跟随移动
- 节点位置自动保存

### 删除节点

| 操作 | 方式 |
|------|------|
| 删除单个 | 选中节点后点击 `×` 按钮 |
| 删除选中 | 选中后按 `Delete` 键 |
| 批量删除 | 框选后按 `Delete` 键 |

### 自动排列

- 点击右下角 `排` 按钮
- 自动整理节点布局，避免重叠

## 连接线

### 创建连接

1. 从节点的输出端口（右侧圆点）拖拽
2. 连接到目标节点的输入端口（左侧圆点）
3. 松开鼠标完成连接

### 删除连接

- 点击连接线，出现 `×` 按钮
- 点击 `×` 删除连接

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Z` | 撤销操作 |
| `Ctrl + Y` | 重做操作 |
| `Ctrl + A` | 全选节点 |
| `Delete` | 删除选中节点 |
| `Ctrl + S` | 保存工作流 |
| `空格 + 拖拽` | 移动画布 |
| `滚轮` | 缩放画布 |
