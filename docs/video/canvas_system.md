# 画布系统使用说明

## 概述

画布是视频工作流的核心编辑区域，支持无限拖拽、缩放、节点管理等操作。

## 画布操作

### 缩放

| 操作 | 方式 |
|------|------|
| 放大 | 点击右下角 `+` 按钮，或 `滚轮`（向上滚），或 `Ctrl + =` |
| 缩小 | 点击右下角 `−` 按钮，或 `滚轮`（向下滚），或 `Ctrl + -` |
| 缩放范围 | 25% ~ 200% |
| 当前缩放 | 右下角显示当前百分比 |

### 平移

| 操作 | 方式 |
|------|------|
| 自由移动画布 | 鼠标中键拖拽，或 `空格 + 左键拖拽` |
| 左右移动画布 | `Shift + 滚轮`（向下滚看向右侧内容，向上滚看向左侧内容） |
| 上下移动画布 | `Ctrl + 滚轮`（向下滚看向下方内容，向上滚看向上方内容） |
| 重置位置 | 刷新页面自动恢复上次位置 |

### 小地图（Minimap）

- 位于画布右下角
- 显示所有节点的缩略位置
- 蓝色方框表示当前视口范围
- 点击小地图可快速导航到指定位置

## 节点操作

### 添加节点

1. 点击画布左上角 `+` 按钮
2. 在弹出菜单中选择节点类型
3. 节点会出现在画布当前视口中心

### 选择节点

| 操作 | 方式 |
|------|------|
| 单选 | 点击节点 |
| 多选 | `Ctrl + 点击` 添加到选区 |
| 框选 | 在空白区域按住左键拖拽 |
| 全选 | `Ctrl + A` |

### 移动节点

- 选中节点后拖拽移动
- 多选时拖拽其中一个，其他跟随移动
- 节点位置自动保存

### 删除节点

| 操作 | 方式 |
|------|------|
| 删除单个 | 选中节点后点击 `×` 按钮 |
| 删除选中 | 选中后按 `Delete` 键 |
| 批量删除 | 框选后按 `Delete` 键 |

### 自动排列

- 点击右下角 `排` 按钮
- 自动整理节点布局，避免重叠
- 排列完成后所有分组框会跟随成员节点重新计算包围盒（实现见 `web/js/workflow_layout.js`）：
  - 分镜节点（shot_frame）的上下顺序按父幕节点 `data.shots` 的数组顺序排列，与 `syncShotFramesToShots` 的权威顺序一致；不在 shots 中的孤儿分镜追加到末尾。不以节点标题排序（标题是 shot_id / shot_number / 兜底文案的混用，无统一顺序语义）
  - 幕节点（shot_group）的上下堆叠顺序按该幕首个分镜的 `shot_number`（跨幕全局连续编号）排序；无分镜数据的幕回退按标题比较
  - 其余节点按标题自然排序 + 拓扑分层布局

## 分组（视觉编组）

分组是纯视觉的组织容器（类似 Miro / FigJam 的编组框），用于把一组相关节点框在一起整体管理。

### 创建分组

| 操作 | 方式 |
|------|------|
| 编组选中节点 | 框选/多选 ≥2 个节点后按 `Ctrl + G`，或右键菜单「编组」 |
| 新建空分组 | 左上角 `+` 菜单 →「分组」，在视口位置创建 400×300 空框 |

### 成员规则

- **拖入拖出自动进出组**：节点拖动结束后，节点中心落在某组框内即自动加入该组；拖出框外自动移出
- 同时落在多个重叠组框时，加入面积最小的组
- **不支持嵌套**：节点加入新组时自动从原组移出
- 组框大小随成员自动收缩包裹（成员包围盒 + 28px 留白）；空分组保留用户放置的位置和大小
- 分镜、分镜组、剧本节点同样可以作为分组成员（只是不支持复制，见下文）

### 分组操作

| 操作 | 方式 |
|------|------|
| 选中分组 | 点击组框标题栏（组选中与节点选中互斥） |
| 整组拖动 | 拖拽标题栏，所有成员一起移动 |
| 重命名 | 双击标题栏文字，回车确认、Esc 取消 |
| 解散分组 | 选中组后按 `Delete`，或 `Ctrl + Shift + G`，或右键菜单「解散编组」，或标题栏 `×` |
| 移出单个成员 | 把节点拖出组框，或选中节点后 `Ctrl + Shift + G` |

解散分组只删除组框，**组内节点全部保留**。

### 实现说明（`web/js/canvas_groups.js`）

- 组数据挂在 `state.groups`（`{id, title, x, y, w, h, nodeIds}`），随 `serializeWorkflow` 存入 `workflow_data.groups`，旧工作流无该字段时按空数组兼容
- 组框 DOM 是 `#canvas` 内的 `.node-group` 元素（`z-index:1` 低于节点），主体 `pointer-events:none`，仅标题栏可交互
- 整组拖动复用 events.js 的 `state.drag` 传动（`drag.groupId` 分支），拖动过程中组框实时跟随成员重算
- 撤销（Ctrl+Z）与工作流重载均走既有全量快照链路，分组随快照恢复；「移动 + 进出组」合并为同一个撤销点

## 复制 / 粘贴 / 再制

### 操作方式

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 复制 | `Ctrl + C` | 复制选中节点（不含连线时仅复制节点本身） |
| 粘贴 | `Ctrl + V` | 在最近鼠标位置粘贴；连续粘贴自动向右下错开 30px |
| 再制 | `Ctrl + D` | 在原位置右下错开 30px 直接复制一份 |

也可以通过右键菜单（画布空白处/节点上右键）执行相同操作。

### 范围与规则

- **分镜（shot_frame）、分镜组（shot_group）、剧本（script）节点不支持复制**——它们与后端数据库记录强绑定（shotId / groupId / scriptId），复制会产生数据歧义；选中它们按 Ctrl+C 会弹出提示
- 复制多选时：可复制节点正常复制，被排除类型跳过并提示
- 选中集**内部**的连线（六类连接数组）会一起复制，粘贴时按 新旧 id 映射重建；与未复制节点之间的连线不会带过去
- 粘贴的节点不继承分组归属、不进入时间轴
- 剪贴板是**页面内存剪贴板**：刷新页面或切换工作流后失效；File 对象（如刚上传未落盘的文件）通过 structuredClone 保留，同页面粘贴仍可上传

### 实现说明（`web/js/canvas_clipboard.js`）

- 复制时深拷贝节点 `{type, title, x, y, data}` + 内部连线
- 粘贴时为每个节点分配 `state.nextNodeId++` 新 id，然后调用 `restoreNode(nodeData)` 实例化——与工作流重载完全同一条复原路径（node_registry 注册表 + if-else 链），保证粘贴产物可随工作流持久化、可撤销
- 粘贴锚点取 `state.lastMouseWorldPos`（mousemove 持续记录的画布坐标），无记录时回退视口左上
- 粘贴副本重置 `uploading` 等运行态标记，避免与原节点共享瞬时状态

## 连接线

### 创建连接

1. 从节点的输出端口（右侧圆点）拖拽
2. 连接到目标节点的输入端口（左侧圆点）
3. 松开鼠标完成连接

### 删除连接

- 点击连接线，出现 `×` 按钮
- 点击 `×` 删除连接

## 快捷键

> 点击画布顶部工具栏的「快捷键」按钮（键盘图标），可随时查看分组说明弹窗（编辑 / 分组 / 画布视图）。弹窗样式跟随工作流浅色 / 暗色主题：按键为键帽样式，鼠标操作为虚线胶囊以示区分。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + C` | 复制选中节点（分镜/分镜组/剧本除外） |
| `Ctrl + V` | 在鼠标位置粘贴；连续粘贴自动向右下错开 |
| `Ctrl + D` | 再制（原位附近直接复制一份） |
| `Ctrl + Z` | 撤销上一步操作 |
| `Delete` / `Backspace` | 删除选中（连接线 → 时间轴片段 → 节点）；作用于分组框时解散分组（保留节点） |
| `Ctrl + G` | 把选中的多个节点编为一组 |
| `Ctrl + Shift + G` | 解散选中分组 / 将选中节点移出分组 |
| 双击分组标题栏 | 重命名分组 |
| `Ctrl + =` / `Ctrl + -` | 放大 / 缩小 |
| `滚轮` | 缩放画布（以鼠标位置为中心） |
| `Shift + 滚轮` | 画布左右平移 |
| `Ctrl + 滚轮` | 画布上下平移 |
| `Ctrl + 空白处拖拽` | 框选多选节点 |
| 拖动空白区域 | 平移画布 |
