# 分镜组节点使用指南

## 概述

分镜组节点是剧本解析后生成的中间层节点，用于管理一组相关的分镜头（通常对应一个场景）。

## 功能

| 功能 | 说明 |
|------|------|
| 分镜组详情 | 查看分镜组包含的所有分镜头 |
| 编辑分镜组 | 修改分镜组名称、描述等信息 |
| 批量管理 | 批量操作分镜组内的分镜头 |
| 视频模型选择 | 为整个分镜组选择默认视频模型 |

## 分镜组结构

```
分镜组（场景1）
├── 分镜1（台词/动作1）
├── 分镜2（台词/动作2）
└── 分镜3（台词/动作3）
```

## 操作说明

### 查看详情

1. 点击分镜组节点的「详情」按钮
2. 弹窗显示所有分镜头列表
3. 每个分镜头显示图片预览和台词

### 编辑分镜组

1. 点击分镜组节点的「编辑」按钮
2. 修改分镜组名称、描述
3. 选择视频模型
4. 点击「保存」

### 创建/编辑分镜

1. 在分镜组详情弹窗中点击「新建分镜」
2. 或点击已有分镜的「编辑」按钮
3. 修改分镜内容（台词、图片、视频设置）

## 与剧本节点的关系

- 剧本节点解析后自动生成分镜组
- 每个场景对应一个分镜组
- 分镜组内的分镜对应剧本中的台词或动作
