# 分镜组节点使用指南

## 概述

分镜组节点是剧本解析后生成的中间层节点，用于管理一组相关的分镜头（通常对应一个场景）。

> 「是否处理人脸」选项：当分镜组选择的视频模型属于 Seedance 2.0 系列（后端 `needs_face_mask === true`，单一事实来源 `SEEDANCE_FACE_MASK_DRIVER_KEYS`）时，节点第 3 列「视频生成」会显示「是否处理人脸」复选框。商业版可勾选，提交视频任务时会附带 `enable_face_mask=true` 走人脸遮盖预处理；社区版复选框置灰并显示「此功能为商业版功能」橙色提示。切换视频模型或生成模式（首帧/参考）时，该字段会随当前模型自动显隐。勾选状态保存在 `node.data.processFace` 中，重载工作流可复原。

## 功能

| 功能 | 说明 |
|------|------|
| 分镜组详情 | 查看分镜组包含的所有分镜头 |
| 编辑分镜组 | 修改分镜组名称、描述等信息 |
| 批量管理 | 批量操作分镜组内的分镜头 |
| 视频模型选择 | 为整个分镜组选择默认视频模型 |
| 是否处理人脸 | 仅 Seedance 2.0 系列视频模型显示；商业版可勾选并随视频提交 `enable_face_mask`，社区版置灰提示（见下文） |

## 分镜组结构

```
分镜组（场景1）
├── 分镜1（台词/动作1）
├── 分镜2（台词/动作2）
└── 分镜3（台词/动作3）
```

## 操作说明

### 查看详情

1. 点击分镜组节点的「详情」按钮
2. 弹窗显示所有分镜头列表
3. 每个分镜头显示图片预览和台词

### 编辑分镜组

1. 点击分镜组节点的「编辑」按钮
2. 修改分镜组名称、描述
3. 选择视频模型
4. 点击「保存」

### 创建/编辑分镜

1. 在分镜组详情弹窗中点击「新建分镜」
2. 或点击已有分镜的「编辑」按钮
3. 修改分镜内容（台词、图片、视频设置）

## 与剧本节点的关系

- 剧本节点解析后自动生成分镜组
- 每个场景对应一个分镜组
- 分镜组内的分镜对应剧本中的台词或动作
