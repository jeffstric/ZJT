# 对话组节点使用指南

## 概述

对话组节点用于管理多角色对话场景，自动将对话文本转换为语音并关联到时间轴。

## 功能

| 功能 | 说明 |
|------|------|
| 多角色对话 | 管理多个角色的对话内容 |
| 自动 TTS | 自动将每句对话转换为语音 |
| 视频参考 | 支持输入参考视频 |
| 时间轴关联 | 生成的语音片段自动添加到时间轴 |

## 对话管理

### 添加对话

1. 选择角色
2. 输入台词内容
3. 设置情感参数（可选）

### 编辑对话

- 修改角色、台词、情感参数
- 调整对话顺序
- 删除对话

### 角色音色

- 每个角色可以绑定不同的参考音色
- 从角色库中自动获取参考音频

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 视频参考输入 | 左侧 | 接收视频节点作为参考 |
| 音频输出 | 右侧 | 输出生成的语音片段 |

## 使用流程

1. 添加对话组节点
2. 添加对话条目（角色 + 台词）
3. 为每个角色设置参考音色
4. （可选）连接视频参考
5. 点击「生成语音」
6. 等待所有语音生成完成
7. 生成的语音自动添加到时间轴

## 与文字转语音的区别

| 特性 | 对话组节点 | 文字转语音节点 |
|------|-----------|--------------|
| 多角色 | 支持 | 不支持 |
| 批量处理 | 自动批量 | 单条处理 |
| 时间轴 | 自动关联 | 手动添加 |
| 适用场景 | 多角色对话 | 单条配音 |
