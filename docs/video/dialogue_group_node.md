# 对话组节点使用指南

## 概述

对话组节点用来管理一个镜头里的多句台词。语音合成在文字转语音节点上完成：对话组按台词创建或打开对应的文字转语音节点，不在自己内部调用音频合成接口。

## 功能

| 功能 | 说明 |
|------|------|
| 多角色台词 | 管理多句对话的角色名和文本 |
| 创建语音节点 | 每一句可以单独创建，也可以一次为全部台词创建文字转语音节点 |
| 角色参考音 | 若对话组里存有该角色的参考音频，或当前世界角色库有 `default_voice`，新节点使用参考音频克隆；否则使用音色库，由用户选择音色 |
| 历史音频 | 以前在对话组里生成过的音频仍可播放、下载、加入时间轴 |
| 时间轴 | 文字转语音节点上的「添加到时间轴」会记到所属对话组，方便按镜头对齐 |

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 分镜输入 | 左侧 | 连接分镜节点后，读取该分镜的 `dialogue` |
| 视频输入 | 左侧 | 保留在页面上，已禁用。新的情感参考视频不再接到对话组 |
| 输出 | 右侧 | 保留原输出端口 |
| 台词参考音色 | 每条台词右侧紫色圆点 | 该句角色能匹配到当前世界的角色，且角色有参考音频（`default_voice`）时，可拖到文字转语音节点的音色输入。匹配不到、或角色没有参考音时不会连上。删掉这句台词会断开它带出去的音色连线，后面台词的连线序号跟着前移 |

## 使用流程

1. 从分镜节点点击「创建对话语音」，或自行添加对话组并写入台词。
2. 在对话组中点击「创建语音节点」或「全部创建语音节点」。
3. 在弹出的文字转语音节点里确认引擎：有参考音频时是「参考音频克隆」，否则是「音色库合成」。也可以把角色节点的音色输出，或对话组里该句台词的参考音色圆点，拖到文字转语音的音色输入上。
4. 在文字转语音节点上点击「生成语音」。
5. 需要进时间轴时，在文字转语音节点或对话组里已有的历史音频上点击「添加到时间轴」。

编辑台词会同步到已关联的文字转语音节点，并清掉该节点上已生成的语音。删除台词只解除这一条的关联并顺延后面的序号，不删除画布上的文字转语音节点。

## 与文字转语音的分工

| 项目 | 对话组节点 | 文字转语音节点 |
|------|-----------|--------------|
| 台词列表 | 管理多句角色和文本 | 一节点对应一句 |
| 合成 | 不合成 | 音色库或参考音频克隆、语速、情感参考音频 |
| 时间轴 | 历史音频仍可加入 | 新生成的音频从这里加入 |

详见 [火山 TTS 音色库](../audio/volcengine_tts.md)。
