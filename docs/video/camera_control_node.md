# 相机控制节点使用指南

## 概述

相机控制节点用于控制视频中的相机运动，支持水平角度、垂直角度和缩放参数，并提供 3D 预览功能。

## 功能

| 功能 | 说明 |
|------|------|
| 水平角度 | 控制相机水平旋转角度 |
| 垂直角度 | 控制相机垂直旋转角度 |
| 缩放 | 控制相机缩放倍数 |
| 3D 预览 | 实时预览相机效果 |

## 参数说明

| 参数 | 范围 | 说明 |
|------|------|------|
| 水平角度 | -180° ~ 180° | 负值向左，正值向右 |
| 垂直角度 | -90° ~ 90° | 负值向下，正值向上 |
| 缩放 | 0.5x ~ 2x | 小于 1 为广角，大于 1 为特写 |

## 3D 预览

- 右侧显示 3D 预览窗口
- 实时反映相机参数变化
- 帮助直观理解相机运动效果

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 输出端口 | 右侧 | 连接到图生视频节点，传递相机参数 |

## 预设运动

系统提供多种预设相机运动：

| 预设 | 说明 |
|------|------|
| 推进 | 相机向前推进 |
| 拉远 | 相机向后拉远 |
| 左移 | 相机向左平移 |
| 右移 | 相机向右平移 |
| 上升 | 相机向上移动 |
| 下降 | 相机向下移动 |
| 环绕 | 相机环绕目标旋转 |

## 使用流程

1. 添加相机控制节点
2. 设置相机参数或选择预设运动
3. 查看 3D 预览确认效果
4. 将输出连接到图生视频节点
5. 生成带有相机运动的视频
