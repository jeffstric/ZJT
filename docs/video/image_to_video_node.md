# 图生视频节点使用指南

## 概述

图生视频节点是视频工作流的核心节点，用于将图片转换为视频。支持多种视频模型和输入模式。

## 支持的视频模型

| 模型 | 说明 |
|------|------|
| sora2 | OpenAI Sora 2（已下线隐藏） |
| vidu | Vidu |
| seedance | Seedance 火山引擎 |
| ltx2_3 | LTX2.3 |
| 其他 | 根据配置可能有更多模型 |

> 说明：`wan22`（Wan2.2）、`ltx2`（LTX2.0）已关闭（`enabled=False`），前端不再展示，也无法新建任务。

## 三种输入模式

### 1. 首尾帧模式（默认）

- **首帧**：视频开始的画面
- **尾帧**：视频结束的画面（可选）
- AI 会在首帧和尾帧之间生成过渡动画
- 适合需要精确控制起止画面的场景

### 2. 多参考图模式

- 上传多张参考图
- AI 综合参考图生成视频
- 适合需要参考多个画面风格的场景

### 3. 文生视频模式

- 仅通过文字提示词生成视频
- 不需要上传任何图片
- 适合创意性较强的场景

## 参数设置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 提示词 | 描述视频内容和运动 | 空 |
| 时长 | 视频时长（秒） | 5 |
| 比例 | 视频宽高比 | 跟随全局设置 |
| 视频模型 | 选择 AI 模型 | 第一个可用模型 |
| 抽卡次数 | 一次生成几个版本 | 1 |
| 运动强度 | 控制画面运动幅度 | 关闭 |

## 参考素材

### 参考音频

- 上传参考音频，AI 会根据音频节奏生成视频
- 支持多个参考音频

### 参考视频

- 上传参考视频，AI 会参考其风格和运动
- 支持多个参考视频

## 算力预估

- 节点会根据选择的模型、时长、比例自动预估算力消耗
- 算力不足时无法提交生成任务

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 输出端口 | 右侧 | 连接到视频节点，传递生成的视频 |

## 使用流程

1. 添加图生视频节点到画布
2. 选择输入模式（首尾帧/多参考图/文生视频）
3. 上传图片或输入提示词
4. 选择视频模型和参数
5. 点击「生成」
6. 等待生成完成
7. 通过连接线将输出连接到视频节点
