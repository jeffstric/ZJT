# 画风设置

## 概述

画风设置用于统一控制工作流中所有图片和视频的美术风格。

## 设置项

### 画风名称

- 可选择预设画风或自定义输入
- 预设画风包括：漫画风格、写实风格、日漫风、美漫风、皮克斯风等
- 画风名称会附加到图片生成的提示词中

### 预设画风列表

| 画风 | 说明 |
|------|------|
| 漫画风格 | 通用漫画风格 |
| 写实风格 | 接近真实照片 |
| 日漫:新海诚风 | 新海诚动画风格 |
| 美漫:漫威风 | 漫威电影风格 |
| 皮克斯风 | 皮克斯 3D 动画 |
| 日漫:宫崎骏风 | 宫崎骏动画风格 |
| 迪士尼风格 | 迪士尼动画风格 |
| 国漫:3D动画风 | 国产 3D 动画 |
| 赛博朋克风 | 科幻赛博朋克风格 |

### 参考图

- 上传一张参考图作为画风参考
- AI 会参考该图的色调、构图、风格

### 构图倾向

- 输入构图偏好描述（如：三分法、对称构图、黄金螺旋等）
- 构图倾向会附加到图片生成的提示词中

## 世界画风同步

- 当工作流画风与世界画风不一致时，显示同步提示
- 点击「同步世界画风」将世界画风应用到当前工作流
- 也可将当前工作流画风同步回世界

## 操作入口

- 点击画布顶部的「画风」按钮打开画风设置弹窗

## 注意事项

- 画风设置对工作流内所有图片生成节点生效
- 修改画风后需要重新生成图片才能看到效果
- 参考图会增加生成时间
