# 文本节点使用指南

## 概述

文本节点是一个纯信息节点，用于在画布上添加文字说明、备注或标注。

## 功能

| 功能 | 说明 |
|------|------|
| 文本输入 | 输入任意文字内容 |
| 位置自由 | 可放置在画布任意位置 |
| 信息标注 | 用于标注场景、备注说明等 |

## 使用场景

- 标注工作流的创作思路
- 记录待修改的内容
- 为团队协作添加说明
- 标记重要的时间节点

## 操作说明

1. 添加文本节点到画布
2. 输入文字内容
3. 拖拽到合适位置
4. 内容自动保存

## 注意事项

- 文本节点不影响视频生成流程
- 仅用于信息标注和记录
- 支持多行文本
