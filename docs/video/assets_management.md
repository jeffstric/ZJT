# 资产管理（角色/场景/道具）

## 概述

资产管理模块用于管理短剧创作中的核心素材：角色、场景（地点）和道具。所有资产都归属于某个「世界」，支持在画布上创建节点或在分镜中关联使用。

## 资产类型

### 角色（Character）

| 字段 | 说明 |
|------|------|
| 名称 | 角色名称 |
| 年龄 | 角色年龄 |
| 身份 | 角色身份/职业 |
| 性格 | 性格描述 |
| 行为习惯 | 行为模式描述 |
| 其他信息 | 补充描述 |
| 参考图 | 角色参考图片 |
| 多套装扮 | 不同装扮的参考图集 |
| 默认语音 | TTS 语音 ID |

### 场景（Location）

| 字段 | 说明 |
|------|------|
| 名称 | 场景名称 |
| 父级场景 | 所属上级场景（支持层级结构） |
| 描述 | 场景描述 |
| 参考图 | 场景参考图片 |
| 多角度图 | 不同角度的参考图集 |

### 道具（Props）

| 字段 | 说明 |
|------|------|
| 名称 | 道具名称 |
| 内容 | 道具描述 |
| 其他信息 | 补充描述 |
| 参考图 | 道具参考图片 |

## 操作入口

### 侧边栏菜单

点击画布左侧的「添加素材」菜单，可以看到：

- **角色** — 打开角色选择弹窗
- **场景** — 打开场景选择弹窗
- **道具** — 打开道具选择弹窗

### 弹窗操作流程

1. **选择世界**：从下拉框选择目标世界
2. **浏览资产**：查看该世界下的所有资产卡片
3. **搜索过滤**：通过关键词搜索筛选资产
4. **选择或创建**：
   - 点击已有资产 → 创建画布节点或关联到分镜
   - 点击「新建」按钮 → 打开创建表单

## 创建资产

### 创建角色

填写以下信息：

- 必填：名称
- 可选：年龄、身份、性格、行为习惯、其他信息
- 上传：参考图片、多套装扮图片、参考语音

### 创建场景

填写以下信息：

- 必填：名称
- 可选：父级场景、描述
- 上传：参考图片、多角度图片

### 创建道具

填写以下信息：

- 必填：名称
- 可选：内容描述、其他信息
- 上传：参考图片

## 资产节点

在画布上创建资产节点后，节点会显示：

- 角色节点：参考图、名称、基本信息摘要
- 场景节点：参考图、名称、描述
- 道具节点：参考图、名称、描述

### 节点用途

- **视觉参考**：提供给 AI 生成时的参考依据
- **信息记录**：集中管理角色/场景/道具信息
- **连接传递**：通过连接线传递给图生视频节点作为参考图

## 分镜关联

### 关联场景

在分镜编辑中，可以为每个分镜指定场景：

1. 打开分镜组编辑弹窗
2. 点击分镜的「场景」字段
3. 从场景选择弹窗中选择
4. 场景信息自动写入分镜数据

### 关联道具

在分镜编辑中，可以为分镜添加道具：

1. 打开分镜组编辑弹窗或分镜详情
2. 点击「添加道具」按钮
3. 从道具选择弹窗中选择
4. 道具信息添加到分镜的道具列表

### 关联角色

角色通过剧本解析自动关联：

- 剧本节点解析后，分镜会自动填充出场角色
- 角色信息用于网格图生成时的参考图匹配

## 编辑和删除

数据库资产的主入口是剧本创作页右侧栏「已入库」，见 [已入库资产管理](../script/script_writer_asset_library.md)。画布编辑弹窗里的删除是快捷方式。

### 编辑资产

- 剧本创作页「已入库」或画布资产卡片上的「编辑」
- 修改资产信息
- 支持添加/删除参考图片
- 仅创建者可编辑；协作者只读，条目上显示创建者 user_id 末 4 位

### 删除资产

- 剧本创作页「已入库」删除确认弹窗（可同时删暂存同名文件）
- 或画布编辑弹窗中的「删除」按钮
- 仅创建者可删
- 删除剧本不会删除已生成的分镜，只解除 `script_id`
- 画布删除后对应节点会从当前工作流移除；分镜引用不会级联删除

## 数据结构

### 分镜中的资产引用

```javascript
{
  db_location_id: 123,           // 场景 ID
  db_location_pic: "url",        // 场景参考图
  location_name: "客厅",         // 场景名称
  characters_present: "1,2,3",   // 出场角色 ID 列表
  props_present: [1, 2],         // 剧本解析的道具 ID
  props: [                       // 手动添加的道具
    { id: 1, name: "手机", reference_image: "url" }
  ]
}
```

## 注意事项

- 资产归属于世界，切换世界后资产列表会变化
- 参考图会影响 AI 生成的结果，建议上传高质量图片
- 删除资产不会自动删除画布上的对应节点
- 场景支持层级结构，可以设置父级场景

### 文件存储一致性（剧本创作器）

剧本创作器中角色/场景/道具以 JSON 文件持久化在 `files/script_writer/{user_id}/{world_id}/{characters,locations,props}/` 下，由 `FileManager.save_character/save_location/save_prop`（剧本经 `save_script`）统一安全写入：

- **文件名跟随内容 name**：写入时文件名严格取自内容中的 `name`（而非调用参数传入的名字）。当二者不一致时，以内容 name 为准生成新文件并自动清理旧名文件，等价于一次安全重命名——避免「列表里显示某个道具、磁盘上却找不到对应文件」的幽灵道具问题。
- **元数据自动保留/补全**：`world_id`/`user_id`/`created_at`/`updated_at` 等字段在写入时自动从旧文件保留、缺失时补全，业务侧编辑只需提供名称/类型/描述/参考图等业务字段，不会因覆盖写入而丢失元数据。
- **非法 JSON 拒绝**：内容若以 `{`/`[` 开头但解析失败（坏 JSON）会被拒绝写入；纯文本等非 JSON 内容仍按原样兼容写入。
- 多角度参考图可以提高 AI 生成的一致性
