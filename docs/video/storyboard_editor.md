# 故事板编辑器

## 概述

故事板编辑器是智剧通平台的核心可视化创作工具，以**分镜板**的方式组织和管理短剧创作流程。区别于 `video_workflow.html` 的节点式画布，故事板编辑器采用**线性时间轴 + 分镜卡片**的布局，更贴近传统影视分镜脚本的工作方式，适合从剧本到成片的端到端流水线创作。

### 适用场景

- 从一份完整剧本出发，自动拆分为多个分镜
- 逐镜生成首帧图、视频、配音
- 批量补全缺失素材，快速产出成片
- 以时间轴方式预览整片节奏

### 页面入口

通过剧本策划页面进入，URL 需携带 `world_id`（必填）和可选的 `episode_number`、`script_id`、`workflow_id` 等参数。每个世界下的首个故事板在创建时会触发**比例门禁**（必须选择 16:9 或 9:16），确认后才允许拆分、生图、生视频等业务操作。

---

## 界面布局

故事板编辑器采用三栏布局 + 顶部工具栏：

### 顶部工具栏（Header）

| 区域 | 说明 |
|------|------|
| 标题区 | 显示故事板标题、集数切换 |
| 算力显示 | 当前账户算力余额，点击可查看算力日志或充值 |
| 全局设置 | 画风、构图倾向、视频比例、预览分辨率（480p/720p/1080p） |
| 导出按钮 | 导出整片或分镜素材 |

### 左栏（Left Sidebar）

左栏包含两个切换 Tab：

- **画面 Tab**：当前分镜的首帧图预览、视频预览、生成按钮、首帧涂色入口
- **对话 Tab**：当前分镜的对话列表（角色、台词、配音状态）
- **分镜助手**（Agent）：基于 LLM 的对话助手，可针对当前分镜修改提示词、调整台词等

### 中栏（Center）

中栏支持两种视图模式切换：

- **时间轴视图（Timeline）**：所有分镜按时间顺序排列，显示每镜的首帧缩略图、时长、视频/配音状态。支持播放整片
- **网格视图（Grid）**：以卡片矩阵展示分镜，适合批量浏览和编辑

### 右栏（Candidates）

候选素材区：展示当前分镜多次生成的历史结果（首帧图、视频），用户可从中选择最满意的一张作为最终使用素材。

## 核心功能

### 1. 剧本拆分（从剧本生成分镜）

进入故事板后，若无分镜数据，系统会提示「从剧本生成分镜」。

**拆分参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 最大分镜时长 | 15 秒 | 单个分镜的最大时长上限 |
| 强制中景 | 开启 | 优先保证中景镜头 |
| 无背景音乐 | 开启 | 拆分时不生成 BGM 标记 |
| 多对话拆分 | 关闭 | 是否将多轮对话拆分为多个分镜 |
| 对白语言 | 中文 | 台词语言 |
| 提示词语言 | 中文 | 画面提示词语言 |
| 质检（QC） | 关闭 | 多轮拆分+质检，耗时与算力显著增加 |
| 质检最大循环 | 2 | 质检最多循环次数（1-5） |

**拆分进度**：异步任务，显示四阶段进度（规划分段 → 逐段拆分 → 合并校验 → 发布分镜）。页面刷新后会自动恢复轮询，无需重新触发。

**模型选择**：支持选择 LLM 模型（默认 deepseek-v4-flash → qwen3.5-plus），并支持思考模式开关。

### 2. 分镜管理

| 操作 | 说明 |
|------|------|
| 添加分镜 | 在时间轴末尾新增空白分镜 |
| 删除分镜 | 单个或批量删除（批量选择模式） |
| 复制分镜 | 复制当前分镜的全部设置 |
| 编辑分镜 | 修改标题、时长、难度、所属幕（act_name） |
| 调整顺序 | 拖拽或按钮移动分镜位置 |

### 3. 首帧图生成

每个分镜需要一张首帧图作为画面基础。

- **单镜生成**：在左栏「画面 Tab」点击「生成首帧」，基于分镜的画面提示词、角色、场景参考图生成
- **批量生成**：时间轴顶部「批量生成首帧」按钮，自动补全所有缺失首帧的分镜
- **首帧涂色**：对已生成的首帧图进行涂色编辑，复用全局图片上色编辑器
- **候选选择**：每次生成会产出多张候选图，可在右栏挑选最满意的一张

**自动补全模式**：

| 模式 | 说明 |
|------|------|
| 均衡模式（balanced） | 社区版默认，速度优先 |
| 质量模式（quality） | 商业版默认，质量优先 |

**场景参考图门禁**：若分镜关联的场景缺少参考图，系统会返回 `waiting_location_references` 错误，并自动重试，直到场景参考图就绪。

### 4. 视频生成

故事板支持三种视频生成模式：

| 模式 | 说明 |
|------|------|
| 首尾帧模式（first_last_frame） | 提供首帧 + 尾帧，生成过渡视频 |
| 多参考图模式（multi_reference） | 提供多张参考图，生成视频 |
| 文生视频 | 仅靠文本提示词生成视频 |
| 对口型（digital_human） | 数字人对口型视频，仅支持单说话角色 |

**视频生成偏好**（齿轮配置，故事板级）：

| 配置 | 说明 |
|------|------|
| 时长模式 | 自动（按配音时长）或指定秒数 |
| 分辨率 | 视频输出分辨率 |
| 裁剪到配音时长 | 开启后视频时长自动对齐配音时长 |

**视频类型切换**：可在普通视频和对口型（数字人）之间切换。对口型模式仅支持单个说话角色，多角色对话会拒绝切换。

**首帧自动注入**：切换到视频生成模式时，系统会自动将当前分镜的首帧图注入到首帧槽位。用户手动移除后，在当前分镜内不再自动注入（切换分镜后重置）。

### 5. 配音 / TTS 生成

- **单镜配音**：基于分镜对话列表中的角色台词和默认语音生成配音
- **批量配音**：时间轴顶部「批量生成配音」按钮，补全所有缺失配音的分镜
- **音频来源**：播放时支持两种音频模式 —— 视频原声 或 对话配音（TTS）

### 6. 批量操作

时间轴顶部提供批量操作工具栏：

| 操作 | 说明 |
|------|------|
| 批量选择 | 进入批量选择模式，勾选目标分镜 |
| 批量生成首帧 | 为选中分镜生成首帧图 |
| 批量生成视频 | 为选中分镜生成视频 |
| 批量生成配音 | 为选中分镜生成配音 |
| 批量删除 | 删除选中分镜 |

批量操作会跳过已有素材的分镜，避免重复消耗算力。

### 7. 自动补全缺失素材

故事板支持**一键补全**所有缺失素材：

- **自动补图**：进入故事板时自动检测缺失首帧的分镜，后台批量生成
- **自动补视频**：自动检测缺失视频的分镜，后台批量生成
- **进度显示**：顶部显示批量任务进度（总数 / 完成 / 运行中 / 失败 / 跳过）

页面刷新后批量任务会自动恢复轮询，继续跟踪进度。

### 8. 时间轴播放预览

故事板内置类剪影的整片播放引擎：

- **画面**：有视频播视频，无视频定格首帧图
- **音频**：配音齐后按对白顺序串行播放 TTS；若用视频原声则保留视频音轨
- **时长**：每镜占用 `scene.duration` 秒，到点强制切下一镜
- **预加载**：进入每镜前预加载视频和全部配音，就绪后再开时钟
- **后台暂停**：页面隐藏或卸载时自动停止播放

### 9. 导出 / 下载

- **整片导出**：将所有分镜视频拼接为完整视频
- **分镜导出**：单独下载某个分镜的视频/首帧图
- **下载机制**：走同源 `/api/download` 代理，避免浏览器弹窗拦截和跨域问题

### 10. 分镜助手（Agent）

每个分镜配备独立的 LLM 对话助手：

- 针对当前分镜调整画面提示词、台词、镜头描述
- 每镜独立隔离运行态，互不干扰
- 支持字号调节（-2 ~ +8 档，照顾大龄用户）
- 支持思考模式（DeepSeek 默认开启）

## 工作流程

### 端到端创作流程

1. **进入故事板**：从剧本策划页面携带 `world_id` 进入
2. **选择比例**：首个故事板需确认视频比例（16:9 / 9:16）
3. **剧本拆分**：选择剧本并配置拆分参数，等待 LLM 自动生成分镜
4. **审核分镜**：检查分镜列表，手动调整顺序、时长、台词
5. **生成首帧**：单镜生成或批量生成所有首帧图
6. **涂色调整**：对不满意的首帧进行涂色编辑
7. **生成配音**：批量生成所有分镜的 TTS 配音
8. **生成视频**：批量生成所有分镜的视频
9. **预览整片**：时间轴播放，检查节奏和画面
10. **导出成片**：导出完整视频

### 快速补全流程

已有分镜但素材不全时：

1. 进入故事板，系统自动检测缺失素材
2. 点击「批量生成首帧」补全所有首帧
3. 点击「批量生成配音」补全所有配音
4. 点击「批量生成视频」补全所有视频
5. 预览并导出

## 候选选择机制

每次生成首帧图或视频时，系统会产出多个候选结果：

- 候选展示在右栏区域
- 用户点击候选即可设为当前分镜的使用素材
- 候选按分镜隔离，切换分镜不会丢失已选候选
- 生成新的候选不会覆盖已有的，可累积挑选

## 预览分辨率与逻辑画布

| 档位 | 短边像素 | 说明 |
|------|----------|------|
| 480p | 480 | 低分辨率，生成快 |
| 720p（默认） | 720 | 标准分辨率 |
| 1080p | 1080 | 高清分辨率 |

预览分辨率影响**主预览画面的逻辑画布**，与视频生成的输出分辨率独立。预览分辨率越高，画面越清晰，但生成耗时也越长。

## 国际化（i18n）

故事板编辑器完整支持中英文切换：

- 加载 `common` 和 `storyboard` 两个翻译命名空间
- 所有 UI 文本通过 `data-i18n` 或 `t()` 函数翻译
- 语言切换实时生效，无需刷新页面

## 注意事项

- **比例门禁**：世界内首个故事板必须选择视频比例后才能操作；门禁期间禁止拆分、生图、生视频、导出
- **场景参考图**：分镜关联的场景必须有参考图，否则首帧生成会被门禁拦截并自动重试
- **对口型限制**：数字人对口型视频仅支持单说话角色，多角色对话分镜无法切换到此模式
- **算力消耗**：质检拆分、高质量模式会显著增加算力消耗
- **页面刷新**：所有异步任务（拆分、批量生成）在页面刷新后会自动恢复轮询，不会丢失进度
- **后台暂停**：切换浏览器标签页或最小化窗口时，播放会自动停止，避免后台出声
