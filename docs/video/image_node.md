# 图片节点使用指南

## 概述

图片节点用于存储和管理图片文件，支持上传、预览、涂色编辑和网格图片生成。

## 功能

| 功能 | 说明 |
|------|------|
| 上传图片 | 支持本地图片文件上传 |
| 图片预览 | 点击预览按钮查看大图 |
| 涂色编辑 | 使用画笔在图片上涂色修改 |
| 网格图片 | 将多张图片合成为网格图 |
| 连接输出 | 连接到图生视频节点或分镜节点 |

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 输出端口 | 右侧 | 连接到图生视频节点（作为首帧/参考图）或分镜节点 |

## 涂色编辑

1. 点击图片节点中的「涂色」按钮
2. 在弹出的编辑器中调整画笔大小、颜色、透明度
3. 在图片上涂抹
4. 支持撤销和清空操作
5. 点击「确认」保存修改

详见 [图片涂色编辑功能](../image/image_coloring_edit.md)

## 网格图片生成

- 可将多张图片合并为 2x2、3x3 等网格布局
- 适用于宫格视频的首帧制作

## 使用流程

1. 添加图片节点到画布
2. 上传图片或通过连接线接收图片
3. 如需编辑，使用涂色功能
4. 将输出连接到图生视频节点或分镜节点
