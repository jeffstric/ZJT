# 图片节点使用指南

## 概述

图片节点用于存储和管理图片文件，支持上传、预览、涂鸦编辑和网格图片生成。

## 功能

| 功能 | 说明 |
|------|------|
| 上传图片 | 支持本地图片文件上传 |
| 图片预览 | 点击预览按钮查看大图 |
| 涂鸦编辑 | 画笔/橡皮擦/文字/矩形标注，确认后替换节点图 |
| 网格图片 | 将多张图片合成为网格图 |
| 连接输出 | 连接到图生视频节点或分镜节点 |

## 连接端口

| 端口 | 方向 | 说明 |
|------|------|------|
| 输出端口 | 右侧 | 连接到图生视频节点（作为首帧/参考图）或分镜节点 |

## 涂鸦编辑

1. 点击图片节点中的「涂鸦编辑」按钮（上传中/无图时禁用）
2. 编辑器默认进入画笔状态，可直接涂鸦；也可切换选择/橡皮擦/文字/矩形工具
3. 支持撤销/重做、清空、更换底图、调整输出比例
4. 点击「确认」后合成新图并上传替换节点图片

详见 [涂鸦编辑功能开发方案](../image/doodle_editor/涂鸦编辑功能开发方案.md)

> 历史：旧版「涂色编辑」入口（▾ 菜单「使用旧版」）已于 2026-09 移除。

## 网格图片生成

- 可将多张图片合并为 2x2、3x3 等网格布局
- 适用于宫格视频的首帧制作

## 使用流程

1. 添加图片节点到画布
2. 上传图片或通过连接线接收图片
3. 如需编辑，使用涂鸦编辑功能
4. 将输出连接到图生视频节点或分镜节点
