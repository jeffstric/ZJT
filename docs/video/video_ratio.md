# 视频比例设置

## 概述

视频比例设置用于统一控制工作流中所有视频的宽高比。

## 支持的比例

| 比例 | 说明 | 适用场景 |
|------|------|---------|
| 9:16 | 竖屏 | 短视频平台（抖音、快手） |
| 3:4 | 竖屏（较宽） | 小红书、Instagram |
| 1:1 | 正方形 | 社交媒体封面 |
| 4:3 | 横屏（较窄） | 传统屏幕 |
| 16:9 | 横屏（默认） | YouTube、电视 |

## 设置方法

1. 在画布顶部找到「视频比例」下拉框
2. 选择所需比例
3. 设置立即生效

## 影响范围

- 所有新创建的图生视频节点
- 所有新创建的分镜视频生成
- 已创建的节点不受影响（使用创建时的比例）

## 最佳实践

| 平台 | 推荐比例 |
|------|---------|
| 抖音/快手 | 9:16 |
| 小红书 | 3:4 或 1:1 |
| YouTube | 16:9 |
| 微信视频号 | 9:16 或 16:9 |
| B站 | 16:9 |

## 注意事项

- 修改比例后，已生成的视频不会自动重新生成
- 建议在开始创作前确定好比例
- 不同比例的视频在同一时间轴中会自动适配
