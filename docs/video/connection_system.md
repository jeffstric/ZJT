# 连接线系统

## 概述

连接线用于在节点之间传递数据，是工作流中节点协作的核心机制。

## 连接类型

### 视频连接（videoConnections）

- 从图生视频节点的输出端口 → 视频节点的输入端口
- 传递生成的视频文件

### 音频连接（audioConnections）

- 从对话组/文字转语音节点的输出端口 → 音频节点的输入端口
- 传递生成的音频文件

### 图片连接（imageConnections）

- 从图片 / 角色 / 场景 / 道具节点的输出端口 → 图生视频节点的首帧 / 尾帧 / 参考图输入
- 图片节点传递 `data.url`，角色 / 场景 / 道具传递 `data.reference_image`
- `portType`：`start`（首帧）、`end`（尾帧）、`ref-image`（多参考图）

### 参考连接（referenceConnections）

- 从图片 / 角色 / 场景 / 道具节点的输出端口 → **图片节点**的紫色参考端口
- 传递参考图片，供图片节点「编辑图片」时作为参考图

### 首帧连接（firstFrameConnections）

- 从图片节点的输出端口 → 分镜节点的首帧输入
- 传递分镜预览图

### 提取帧连接（extractFrameConnections）

- 从视频节点 → 提取帧节点
- 传递视频用于帧提取

## 创建连接

1. 将鼠标悬停在节点的输出端口（右侧圆点）
2. 端口高亮时按住左键拖拽
3. 拖拽到目标节点的输入端口（左侧圆点）
4. 松开鼠标完成连接

## 删除连接

1. 点击连接线使其高亮
2. 连接线中间出现 `×` 按钮
3. 点击 `×` 删除连接

## 连接规则

- 同类型端口才能连接
- 一个输入端口只能接收一个连接
- 一个输出端口可以连接多个输入端口
- 不允许创建循环连接

## 注意事项

- 删除节点时，相关连接线自动删除
- 连接线跟随节点移动自动调整
- 连接状态自动保存到工作流
